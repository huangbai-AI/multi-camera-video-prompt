# 多机位视频提示词合同

## 何时读取

编写完整多机位提示词、修复镜头连续性或把单机位方案改成多机位方案时读取本文件。

## 输入整理

先提取用户已经明确的信息：

- 主体：人物或物体的身份、数量、外观和固定特征；
- 场景：地点、时间、光线、门窗、家具和关键道具的位置；
- 事件：主要动作、剧情起点、过程和结果；
- 规格：时长、画幅、清晰度和视觉风格；
- 参考素材：每张图片、视频或音频负责传递的属性；
- 镜头：用户指定的景别、机位、运镜、禁用项或参考节奏；
- 声音：配乐、对白、独白、音效、环境声或静音；
- 输出方式：自然语言分镜或按秒时间线。

参考素材只传递用户指定的属性。角色图中的背景、场景图中的人物、样片中的品牌和声音都不能自动迁移。

## 输出结构

把完整提示词放进一个 `text` 代码块，并按以下顺序书写：

### 主体

写清谁在什么环境完成什么事件。存在参考素材时，逐项写明每份素材的职责和边界。

### 风格

写清时长、画幅、清晰度、写实或动画形式、光线、色彩、材质和镜头基调。界面设置与文字要求保持一致。

### 分镜

默认用自然语言依次描述镜头。每个镜头说明：

1. 当前景别与机位；
2. 观众需要看清的人物、动作、表情或空间关系；
3. 人物和道具在镜头结束时的状态；
4. 下一个镜头从哪个动作阶段接上。

用户明确要求按秒、节拍同步或严格时长分配时，使用连续且不重叠的时间段。时间段从 0 秒覆盖到总时长，不留空。

### 声音

根据用户要求组合以下内容：

- BGM：类型、节奏、情绪变化和结尾；
- 对白或独白：说话人、原文、语气、开口或画外音；
- 音效：与动作对应的声音；
- 环境声：空间中持续存在的底噪；
- 静音：明确无配乐、无对白或完全静音。

用户要求“无 BGM、只有音效”时，明确写“无 BGM”，保留动作音效、环境声和用户要求的对白，不添加旋律或节拍铺底。

### 限制

只写当前任务最容易失败的三至八项，优先处理：

- 人物身份、数量、服装和外观漂移；
- 场景结构、光线方向和道具位置变化；
- 屏幕方向、视线和人物站位跳变；
- 连续动作重复、重置、漏步或瞬移；
- 接触关系、手部、身体比例和透视错误；
- 镜头密度超过时长能够承载的范围；
- 额外字幕、品牌、水印、对白或配乐。

## 镜头决策

每次切镜只增加一个主要观看重点：

| 观看重点 | 优先镜头 |
| --- | --- |
| 场景布局、人物位置 | 全景、中远景 |
| 主要动作、人物距离 | 中景 |
| 表情、情绪反应 | 近景 |
| 手部、产品、道具细节 | 特写 |
| 对话与视线关系 | 过肩镜头、双人中景 |
| 连续移动过程 | 跟拍、横移、稳定推拉 |

动作复杂时使用简单机位。需要交代空间时，先给观众看清人物与环境的关系，再进入近景或特写。

## 连续性检查

### 空间

- 门、窗、家具、光源和主要道具的位置不变；
- 人物保持合理的左右关系和距离；
- 摄影机维持轴线，跨轴前先建立新的方向；
- 过肩镜头中的视线方向互相匹配。

### 动作

- 切镜前后的动作处于同一阶段；
- 接触同一物体时，手、身体和物体的位置连续；
- 动作完成后再切到结果，避免过程缺失；
- 同一动作不在新镜头中从头重复。

### 视觉

- 人物脸、发型、服装、年龄和数量保持一致；
- 场景光线、色调和天气保持一致；
- 焦段和透视自然，画幅不压缩人物比例；
- 近景和特写保留足够空间，避免切掉关键动作。

## 信息密度

镜头数量由时长和动作复杂度共同决定。短时间内需要完成多个动作时，优先保留剧情必须看清的动作，并合并用途相近的镜头。不要通过高速切镜掩盖动作过多的问题。

## 交付检查

- 五部分完整且顺序正确；
- 每次切镜都有明确的观看目的；
- 分镜默认使用自然语言；
- 用户要求时间段时，时间连续覆盖总时长；
- 前后镜头的站位、朝向、视线和动作阶段能够衔接；
- 声音符合用户选择；
- 未添加用户没有要求的剧情、角色、品牌、字幕或平台操作。
